Each record states one decision that shaped this package: the context, the decision, the alternatives it rules out
and what follows from it. The records were written on 2026-11-24, retrospectively, from the repository and the paper;
the date of each is when the decision first appears in the repository. The alternatives are reconstructed, not minutes
of a deliberation. Records are not rewritten; a later decision that replaces one is a new record that says so. Format:
Nygard, with an explicit list of alternatives.
